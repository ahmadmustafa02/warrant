Warrant

Stop the agent from doing what the document asked.

The user asked for a summary. The document asked for a side effect.

The problem

The model only writes “call send_email.” The agent loop is what sends the mail.

Warrant sits on that loop. It does not try to make the model honest.

What is allowed

  1. Only the latest user message grants a tool.
  2. An email address must be one the user typed, or a lookup of the person they named.
  3. A secret the user did not authorize is removed. A link carrying it is stopped.
  4. A harmless new tool is remembered. A risky new tool, or one that gains a parameter, stays blocked until a person approves it.

The numbers

Tuned lab, Groq openai/gpt-oss-20b.

Guard off: 17 / 60 hijacked, benign-pass 23 / 24.

Guard on: 60 / 60 stopped, benign-pass 22 / 24.

Held-out attacks: 15 / 15 stopped. Those cases were not used to tune the guard.
